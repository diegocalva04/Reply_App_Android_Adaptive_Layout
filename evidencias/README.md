Los registros originales de compilación, análisis estático, pruebas y rotación
se encuentran en `resultados/`. El XML de Android Studio conserva la repetición
del grupo expandido; los registros de AndroidJUnitRunner documentan los cinco
casos distribuidos por ancho. La matriz y las limitaciones están en
[`docs/VALIDACION.md`](../docs/VALIDACION.md).

Las capturas reflejan momentos reales del desarrollo. El historial publicado
incluye un commit documental posterior a las capturas de Git y GitHub.
